    What happens next

    • Nothing is imported until you review the preview and confirm.
    • Two layouts are supported: daily rows (In/Out columns) or a punch log (one row per punch). Multiple punches per day are kept.
    • Duplicate key: Employee ID + timestamp + punch type. Re-uploading the same file is safe.
    • Different times for an already-imported day are held for reconciliation — the original data is never overwritten.
    • The actual vendor export format has not been supplied; the sample template documents the supported layouts.
